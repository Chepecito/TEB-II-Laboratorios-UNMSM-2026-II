# Taller de Equipos Biomédicos II – UNMSM 2026-II

Escuela Profesional de Ingeniería Biomédica · Universidad Nacional Mayor de San Marcos

## Sobre este repositorio

Este repositorio reunirá todos los laboratorios del curso **Taller de Equipos Biomédicos II**. Cada práctica tendrá su propia carpeta con el firmware, los datos medidos, los scripts de análisis y la documentación (esquemáticos, diagramas y resultados), para que todo el trabajo del ciclo quede en un solo lugar y sea fácil de revisar y reproducir. Los laboratorios se irán agregando a medida que se desarrollen.

## Laboratorios

| N.º | Tema | Carpeta | Estado |
|---|---|---|---|
| 1 | Generación y calibración de una señal analógica con ESP32 (DAC y PWM filtrado) | [`TEB-II-Lab1-DAC-PWM-ESP32/lab1`](TEB-II-Lab1-DAC-PWM-ESP32/lab1) | En curso |

## Organización de cada laboratorio

```
firmware/    Código para el microcontrolador

docs/        Esquemáticos, diagramas y gráficas de resultados

README.md    Objetivos, fundamento, procedimiento y resultados de la práctica
```
